# pairwise-timecode-sync

多机位拍摄完成后，现场录音和摄影机时间码差了 8 帧，后期对轨时演员口型对不上；LTC 解码按固定阈值切片，低电平声道被当成噪声，时间码整段丢失；drop-frame 标记没解析，长素材每小时累计偏移三秒半；jam sync 之后摄影机自由运行，晶振漂移在四小时后积累到两帧；时间码在午夜跨天，比较大小按字符串做，后一天被排到前一天前面；音频采样计数与时间码帧号各自独立，采样率 48k 与 23.976 帧的换算用了整数除法；genlock 信号丢失后没有重新锁定，多机位帧相位错开半帧；时间码偏移按帧数配置，但不同机位帧率不同，偏移量不能通用；LTC 与 VITC 同时存在且不一致，解码器取了先到的那个；导出 XML 时时间码写成非 drop-frame 格式，剪辑软件重新解释后整体偏移。media/timecode_sync.py 是核心，tests/test_timecode_sync.py 15个红。要修的是：按帧比较偏移；自适应阈值；解析 drop-frame；按漂移校正；跨天归一；采样与帧号换算；重新锁定检测；按帧率换算偏移；优先级固定；导出保持格式。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
